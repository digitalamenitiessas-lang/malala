# Lo que el sistema todavía no hace
palabras: AFIP, ARCA, factura electrónica, facturación electrónica, Excel, CSV, planilla, consignación, productos a comisión, ocupación por hora, tareas, Trello, sueldo neto, impuestos IVA
quién: dueño/admin, encargada, empleada

Cosas que preguntaron y el sistema hoy NO tiene. Si preguntan por alguna, decilo claro y no inventes una forma de hacerlo: se pueden pedir como funcionalidad nueva (se cotizan aparte).

## No existe hoy
- **Factura electrónica (AFIP / ARCA):** el sistema no emite facturas. Las "facturas" que aparecen en Gastos son las de los proveedores: el número que se anota al cargar una compra.
- **Exportar a Excel o CSV:** no hay. Lo más cercano es guardar los reportes en PDF ("Reportes" → "Exportar PDF", o Ctrl+P → "Guardar como PDF").
- **Productos en consignación** (el proveedor deja la mercadería, se le paga cuando se vende y la vendedora cobra un monto fijo): no hay un circuito propio. Se puede manejar a mano: el producto como reventa, la comisión de la línea ajustada para que dé el monto fijo y lo que se le debe al proveedor como gasto pendiente a su nombre.
- **Ocupación por hora** (qué horas o qué profesionales están más ocupados): no hay un reporte de eso, y la agenda casi no se usa, así que tampoco hay datos de horarios.
- **Tareas internas** tipo Trello, **impuestos** (IVA, IIBB) y **estados contables** (situación patrimonial, flujo de efectivo formal): no están.

## Ojo con / casos comunes
- Si alguien lo necesita, se puede dejar el pedido con reportar_problema aclarando que es un pedido de funcionalidad, no un error.
- La IA conectada solo consulta: tampoco puede cargar ni corregir datos.
